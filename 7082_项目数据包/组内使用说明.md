## 二、快速开始

### 1. 装依赖

```bash
cd 7082_项目数据包
python -m venv .venv
.venv\Scripts\pip install yfinance pandas requests beautifulsoup4 lxml
```

> 需要 Python 3.10+（本机用 3.14 验证通过）。

### 2. 看数字台账

```bash
python -c "import json; d=json.load(open('data/NVDA/registry.json',encoding='utf-8')); print(len(d), 'facts'); [print(k, v['value'], v['unit'], v.get('period_end')) for k,v in list(d.items())[:10]]"
```

或用 Excel 打开 `prices_1d.csv` 看行情。

### 3. 校验报告里的每个数字

```bash
.venv\Scripts\python -m tools.verify reports\NVDA_draft.md NVDA
```

**规则：校验器的 [MISS] 列表必须清零，报告才能定稿。**

## 三、数据口径（写报告前必读）

| 公司 | 财年结束 | 最新完整财年 |
|---|---|---|
| NVDA | 1 月底 | FY2026（2026-01-25 结束） |
| MSFT | 6 月底 | FY2026（2026-06-30 结束） |
| PLTR | 12 月底 | FY2025（2025-12-31 结束） |

- 季度 Q4 在 XBRL 中通常不单列（10-K 只报年度），季度序列以可得的最全为准。
- 现金流量表在 10-Q 只报 YTD，季度现金流是用差分还原的（`sec.ytd_to_quarters`）。
- 电话会 transcript 未获取（SeekingAlpha 付费墙），改用 **SEC 8-K earnings press release**（官方）。
- Yahoo Finance 是第三方市场数据，引用时写 "Source: Yahoo Finance, retrieved 2026-11-18"。

## 四、引用规范（重要）

1. **禁止手写数字**。所有数字从 `registry.json` 取，或用代码从原始数据算。
2. 每个财务数字标注来源：`SEC 10-K FY2026, accession 0001045810-26-000021`。
3. 行情数字标注：`Yahoo Finance, 2026-11-17 close`。
4. 新闻只作事件线索，不作数据源。
5. 报告定稿前必须跑 `tools/verify.py`，未匹配数字清零。
6. **电话会**引用写 `[<Q> <FY> earnings call, <日期>, StockAnalysis/Quartr]`；管理层口头数字不冒充 10-Q 数字。
7. **Seeking Alpha** 只有公开 RSS 元数据：只能引标题/作者/日期，正文写 `data unavailable`。
8. 拿不到的数据一律按 `data/UNAVAILABLE.md` 的标准句式写 `data unavailable`，不许猜。

## 六、常见问题

**Q：`build_dataset.py` 报 403？**
A：SEC 要求 User-Agent。设置环境变量：`set SEC_UA=你的姓名 你的邮箱`（Windows）后重跑。

**Q：没有 `companyfacts.json` 能跑吗？**
A：读 `registry.json` 写报告不需要；跑 `build_dataset.py` 会自动从 SEC 下载。

**Q：季度现金流 MSFT 为什么只有 10 季？**
A：MSFT 早期 10-Q 的 YTD XBRL 数据不完整，不是抓取错误。

**Q：能直接用 Yahoo Finance 重新抓价格吗？**
A：可以，`python -m tools.prices`（注意 Yahoo 可能限流，稍后重试）。
